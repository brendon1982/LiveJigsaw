# Live Jigsaw

A browser jigsaw game built around a live, self-running scene. This Phaser 4 starter shows two views of a single dynamic texture with an animated windmill. The source runs without player input. Piece shapes, dragging, and snapping are future work.

## Local development

Use Node.js 22.12 or newer and pnpm.

```sh
pnpm install
pnpm dev
```

Run `pnpm check` for type checking, `pnpm build` for the production build, and `pnpm preview` to serve that build locally.
